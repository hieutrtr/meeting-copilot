## Scope

A pure, side-effect-free function:

```ts
detectCandidate(text: string, opts?: { minLen?: number }): {
  isCandidate: boolean;
  signals: HeuristicSignal[];
}
```

Where `HeuristicSignal` is one of:

- `"qmark"` — text ends with `?` (after trimming).
- `"wh-en"` — English wh-word + auxiliary/modal pattern (`what is/are/was/were/do/does/did`, `why`, `how`, `when`, `where`, `who`, `which`).
- `"wh-vi"` — Vietnamese question patterns (`gì`, `nào`, `sao`, `tại sao`, `thế nào`, `ở đâu`, `khi nào`, `bao giờ`, `đúng không`, `phải không`, `có … không`, `đã … chưa`).
- `"modal-en"` — English modal-aux inversion: `can/could/would/should/will/may/might + you/we/I/they`, plus `do you`, `did you`, `is there`, `are there`.
- `"long-stmt"` — text length > 50 chars combined with one of the above (used as a positive co-signal, never alone).

Decision: `isCandidate = signals.length > 0`. The intonation flag from STT prosody (mentioned in ARCH §5.1 third bullet) is **out-of-scope** for v0.2 — not all providers expose prosody and MLX whisper does not. Documented as a deferred enhancement in the risk section.

## Acceptance Criteria

Verbatim from plan (T-2.1):

> Unit test 50 sample (25 question, 25 không), precision ≥ 0.7, recall ≥ 0.8.

Translated:

- 50-sample text fixture: 25 ground-truth questions, 25 ground-truth non-questions.
- Coverage: ≥ 10 Vietnamese (mix of qmark, wh-vi, modal), ≥ 10 English (qmark, wh-en, modal), ≥ 5 edge cases (wh-word in declarative; question without `?`).
- Compute `precision = TP / (TP+FP)` and `recall = TP / (TP+FN)` over all 50.
- Pass gate: `precision ≥ 0.70` AND `recall ≥ 0.80`.
- Numeric metrics recorded in `T-2.1-review.md`.

## TDD Plan

Test file: `src/detector/heuristic.test.ts`. Fixture file: `shared/fixtures/question-detector-50.json`.

Test cases (Vitest):

1. **Fixture shape** — fixture has exactly 50 entries, exactly 25 with `expected: true` and 25 with `expected: false`. Guards against accidental edits skewing the metric.
2. **Per-sample regression suite** — `it.each(fixture)` asserts the detector verdict matches `expected`. Failures here are diagnostic, not gating (we expect a small number of misclassifications inside the precision/recall envelope).
3. **Aggregate precision/recall gate** — single `it("meets precision ≥ 0.70 and recall ≥ 0.80")` computes TP/FP/FN, asserts both thresholds. This is the AC gate.
4. **Signal correctness** — spot-check that obvious questions surface the expected signals (e.g. "What is the deadline?" → includes `wh-en`; "Bạn nghĩ sao?" → includes `qmark` and `wh-vi`).
5. **Determinism** — same input twice = same output (pure function).
6. **Empty / whitespace input** — returns `isCandidate: false`, `signals: []`.

## Risk + Mitigation

| Risk | Mitigation |
|---|---|
| **False positives from wh-word in declarative sentences.** "I know what the deadline is." contains `what` + `is` but is not a question. | Stage 2 (T-2.3) Haiku filter is the explicit safety net per ARCH §5.1. T-2.1 is intentionally permissive: precision floor is only 0.70 because Haiku catches the slack. The 50-sample fixture includes ≥ 3 declarative-with-wh examples to keep us honest. |
| **Vietnamese diacritics edge cases.** "tai sao" (no diacritics) vs "tại sao" — users may type without accents in transcripts when STT confidence is low. | Match against both diacritic-stripped and original forms; document as a known partial coverage. |
| **Prosody / intonation signal absent.** ARCH §5.1 mentions intonation rise as a third Stage-1 signal but MLX whisper does not expose it. | Documented as deferred. The text-only signals already comfortably hit the AC envelope on the fixture. |
| **Fixture overfit risk.** A 50-sample fixture is small; the detector might pass the gate by accidentally memorizing patterns the author wrote. | T-2.10 E2E with the 30-min fixture (real or synthetic) is the empirical re-verification. T-2.1 fixture is the unit-level guard; the phase-level gate is T-2.10. |

## Out of Scope (explicitly deferred)

- Prosody/intonation flag (no MLX support).
- Embedding-based similarity (deferred to T-2.4 dedup, and even there hash-only ships in v0.2).
- Multi-lingual beyond EN+VI (TH/JA/ZH not required by current PRD personas).
