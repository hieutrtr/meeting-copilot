## Hand-off to T-2.3

T-2.3 (Haiku LLM filter) consumes one `Utterance` per call via:

```ts
const window = createSlidingWindow();
function onChunk(chunk: TranscriptChunk) {
  for (const utt of window.push(chunk)) {
    const heur = detectCandidate(utt.text);   // T-2.1
    if (!heur.isCandidate) continue;
    classifyWithHaiku(utt);                   // T-2.3
  }
}
// On meeting end:
for (const utt of window.flush()) onUtterance(utt);
```

T-2.6 will be the integrator that lives at the React/queue boundary; T-2.3 only needs the `Utterance` shape, which is now stable in `shared/types.ts`.
