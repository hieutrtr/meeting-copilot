### Per-call cost projection (for T-2.7 cost guard input)

Worker module itself — **$0.000000 / call**. No SDK call. The downstream `askClaude()` (T-1.10 Sonnet 4.6) cost is unchanged from Phase 1; the per-question Sonnet warm-cache cost is ≈ $0.005 per turn under Phase-0 spike measurements (`experiments/T-0.5/`). The worker forwards `result.usage` + `result.costUsd` verbatim into the `onItemDone(item, result)` callback so T-2.7 can sum across items without touching worker internals.

### Latency

The worker adds two synchronous JS hops on the hot path:
1. `markAuto` (zustand `set` → 1 array prepend) — sub-microsecond.
2. `queue.dequeue` + `queue.complete` — sub-microsecond (T-2.5 measured).

Plus 2 microtask hops for the level-triggered notify-renotify pattern. Worst-case worker overhead per item is < 1 ms before ask() is invoked. Well under the < 50 ms hop budget per ARCH §12.

## Hand-off to T-2.7 (cost guard)

T-2.7 reads usage from `onItemDone(item, result)`:

```ts
const totalTokens = { in: 0, out: 0, costUsd: 0 };
const worker = createQueueWorker({
  queue,
  ask: askClaude,
  store: useQuestionStore.getState(),
  getContextDoc: () => useContextStore.getState().content,
  onItemDone: (_item, result) => {
    totalTokens.in += result.usage.input_tokens ?? 0;
    totalTokens.out += result.usage.output_tokens ?? 0;
    totalTokens.costUsd += result.costUsd;
    // T-2.7: project to $/h, fire alert if > $0.50/h.
  },
});
```

Worker forwards Sonnet usage; T-2.7 also reads Haiku usage from the T-2.3 classifier on the upstream side of the queue. The cost guard sums both.

## Hand-off to T-2.8 (UX hook)

T-2.8 wraps the worker in a React hook that mirrors `useAskClaude`'s shape:

```ts
function useQueueWorker(queue, ask, store, contextGetter): {
  status, text, error, usage, costUsd, cacheReadRatio, currentItemId
} {
  const [snapshot, setSnapshot] = useState({...});
  const workerRef = useRef<QueueWorker | null>(null);
  useEffect(() => {
    const w = createQueueWorker({
      queue, ask, store, getContextDoc: contextGetter,
      onItemStart: (item) => setSnapshot({status: "streaming", text: "", currentItemId: item.id, ...}),
      onItemDelta: (_, _, accumulated) => setSnapshot(s => ({ ...s, text: accumulated })),
      onItemDone: (_, result) => setSnapshot(s => ({ ...s, status: "done", usage: result.usage, costUsd: result.costUsd, cacheReadRatio: result.cacheReadRatio })),
      onItemError: (_, error, partial) => setSnapshot(s => ({ ...s, status: "error", error, text: partial ?? s.text })),
    });
    workerRef.current = w;
    return () => w.stop();
  }, []);
  return snapshot;
}
```

The AnswerPanel re-uses verbatim. T-2.8 also adds a `method: "auto"` badge in the header to distinguish from manual mark.
