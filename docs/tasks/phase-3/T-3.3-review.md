### Backoff schedule trace (default config)

```
attempt | pre-attempt sleep (no jitter) | cumulative wall-clock | next_delay output
   1    |       0 ms                    |   0 ms                | 200 ms (initial)
   2    |     200 ms                    | 200 ms                | 400 ms
   3    |     400 ms                    | 600 ms                | 800 ms (would-be next)
budget exhausted → SttError::ProviderUnavailable { attempts: 3 }
```

With `jitter = 0.25`: each sleep ∈ `[0.75d, 1.25d]` → worst-case wall-clock = 250 + 500
= 750 ms. Best-case = 150 + 300 = 450 ms.

### `connect_with_backoff` control flow

```rust
fn connect_with_backoff(&self) -> Result<Sock, SttError> {
    let max = self.config.backoff.max_retries.max(1);   // normalize 0 → 1
    let mut delay = self.config.backoff.initial_delay;
    let mut last_error = String::from("(no attempt made)");

    for attempt in 1..=max {
        match self.connect() {
            Ok(sock) => return Ok(sock),                 // success — return on first hit
            Err(e @ SttError::Config(_)) => return Err(e), // config errors NOT retried
            Err(e) => {
                last_error = format!("{e}");
                if attempt < max {                        // skip sleep on final attempt
                    let j = self.config.backoff.jittered(delay, clock_jitter_sample());
                    std::thread::sleep(j);
                    delay = self.config.backoff.next_delay(delay);
                }
            }
        }
    }
    Err(SttError::ProviderUnavailable { attempts: max, last_error })
}
```

Properties:
- Single attempt on success → no sleep before attempt 1.
- Config errors short-circuit before the sleep gate → fast-fail (< 50 ms in the test).
- Final attempt's failure does NOT sleep → wall-clock budget = sum of pre-attempt sleeps,
  not pre + post.
- `last_error` always set to a non-empty string before reaching the `ProviderUnavailable`
  return when `max ≥ 1` (initial value only persists if `max == 0`, which can't happen
  due to the `.max(1)` normalize).
