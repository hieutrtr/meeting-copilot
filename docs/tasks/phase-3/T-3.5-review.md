## Privacy / leak audit

T-3.9 telemetry will consume snapshots from this meter. The meter's persisted state is exclusively:

- `audioSeconds` (number) per provider
- `costUsd` (number) per provider
- `activeProvider` (enum string in `{mlx, fake, deepgram, elevenlabs}`)
- `elapsedMs`, `projectedCostPerHourUsd` (derived)

No `text`, `pcm`, `audio` (bytes), `apiKey`, or transcript fragments touch the meter's state. `recordTranscriptChunk` reads only `chunk.startTs` and `chunk.endTs`; the chunk's `text` is never copied or stored. T-3.9's privacy grep test will exercise the same code path and confirm.

API keys: not handled here at all. The Rust-side adapters (T-3.2, T-3.4) own key plumbing via env vars; the TS-side meter is provider-agnostic.
