### Mock WS server lifecycle (test-correctness trace)

```
Server (tungstenite::accept_hdr)        Client (tungstenite::connect)
─────────────────────────────────       ──────────────────────────────
[bind 127.0.0.1:0] → port               
[accept TCP]                            [open TCP to 127.0.0.1:port]
[read upgrade req] ← ─ ─ ─ ─ ─ ─ ─ ─ ─  [send GET / Upgrade: ws]
[callback: capture Authorization]
[send 101] ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ →  [recv 101]
[for body in responses: send Text]      
   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ →  (responses buffered in client RX)
                                        [transcribe_chunk: send Binary PCM]
[set_read_timeout(400 ms) × 5]          [set_read_timeout(drain_timeout)]
[read Binary] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   
[loop 4× read → timeout]                [drain: read Text × N → timeout]
[close]                                 [return Vec[finalized segments]]
```

**Bounded latency**: server waits at most 400 ms × 5 = 2 s before closing. Client drains
at most `drain_timeout` (300 ms in round-trip test). No path can hang indefinitely.
