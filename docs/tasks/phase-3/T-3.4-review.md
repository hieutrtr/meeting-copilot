```

t = 0+:   server: bind 127.0.0.1:0 → accept() blocks.
t = 1ms:  test: ElevenLabsAdapter::new(cfg) — validates key (Some("xi-abc")), sets
          socket = None, session_base_ts_ms = None.

          Branch: socket.is_none() → connect_with_backoff() → connect() →
          tungstenite::connect(req) where req carries xi-api-key header.
          Server: accept() returns; tungstenite::accept_hdr captures headers,
          including xi-api-key = "xi-abc". Handshake completes.
          adapter.session_base_ts_ms = Some(5_000).
t = 2ms:  Server: sends GOLDEN_INTERIM, GOLDEN_METADATA, GOLDEN_PING, GOLDEN_FINAL
          (4 text frames in order).
          adapter sends Message::Binary(encode_linear16(samples)).
t = 3ms:  adapter sets read_timeout = 300 ms, enters drain loop.
          Iter 1: socket.read() → Ok(Text(GOLDEN_INTERIM)).
                  parse_transcription: msg_type = "transcription", is_final = false →
                  Ok(None). out unchanged.
          Iter 2: socket.read() → Ok(Text(GOLDEN_METADATA)).
                  parse_transcription: msg_type = "metadata" ≠ "transcription" →
                  Ok(None). out unchanged.
          Iter 3: socket.read() → Ok(Text(GOLDEN_PING)).
                  parse_transcription: msg_type = "ping" ≠ "transcription" →
                  Ok(None). out unchanged.
          Iter 4: socket.read() → Ok(Text(GOLDEN_FINAL)).
                  parse_transcription: msg_type = "transcription", is_final = true,
                  transcript = "What time is the meeting?" (non-empty) →
                  Ok(Some(SttSegment { text, start_ts_ms = 5_000 + 1500 = 6_500,
                                        end_ts_ms = 5_000 + 3800 = 8_800,
                                        is_final = true,
                                        confidence = Some(0.987) })).
                  out.push(seg).
          Iter 5: socket.read() → Err(WouldBlock | TimedOut) — drain timeout
                  fired since server has no more frames.
                  break.
          closed = false, so socket retained for next call.
          Return Ok(vec![seg]).
t = 5ms:  test: assert segs.len() == 1, text == "What time is the meeting?",
          start_ts_ms == 6_500, end_ts_ms == 8_800, is_final, confidence is_some.
          server.join() — server thread already exited after responses + close.
```

## API-Key Hygiene

**Grep audit**: T-3.4 introduces no log output that touches `api_key`. The
`SttError::ProviderUnavailable.last_error` field carries the `tungstenite::Error`
display string, which does not include header values. The `SttError::Config(_)`
construction-time error is a static string referencing `ELEVENLABS_API_KEY` — does
not include the (empty / `None`) key value.

**Defense-in-depth grep**: `grep -E "(xi-|Token )" crates/stt-mlx/src/providers/elevenlabs.rs`
shows only the auth-header literal (`"xi-api-key"`) and the auth-header construction
site — no log/print/format calls embed the key. T-3.9 telemetry will add an automated
grep test asserting these substrings are absent from log lines.

**Header-value formatting**: `HeaderValue::from_str(api_key)` accepts the raw key.
Real ElevenLabs keys are ASCII alphanumeric + dashes; if the key contains non-visible
ASCII the construction error path returns `SttError::Config("xi-api-key header value: ...")`
which carries `from_str`'s error message (a description of the invalid byte position,
not the byte value itself). Construction-time only — does not retry.
