## 5. Threat-model walkthrough (R-4 in INDEX)

| Attack vector | Defence layer | Test |
|---|---|---|
| `MCP_BRIDGE_HOME=/tmp/../etc` | (1) `containsTraversal` rejects `..` substring | `status.test.ts > rejects MCP_BRIDGE_HOME with `..` traversal as BridgeConfigInvalid` (asserts dial not called) |
| `MCP_BRIDGE_HOME=~/foo` | (1) Non-absolute reject (no leading `/`) | `socket.test.ts > rejects a tilde-prefixed env override` + `status.test.ts > rejects MCP_BRIDGE_HOME with non-absolute value as BridgeConfigInvalid` |
| Stale socket from crashed prior daemon | (2) Rust `recover_stale_socket` dial-or-unlink | `mcp_rpc.rs > recover_stale_socket_unlinks_dead_file` |
| Two MC processes contending for one socket | (3) Live-listener probe refuses bind | `mcp_rpc.rs > recover_stale_socket_refuses_when_listener_alive` |
| Daemon hangs and never replies | (4) `responseTimeoutMs` (default 1000ms) on dial | `socket.test.ts > rejects when the response timeout fires after connect` |
| Daemon refuses connect (e.g. `EACCES`, `ENOENT`) | (4) `connectTimeoutMs` (default 200ms) + error-event propagation | `socket.test.ts > rejects when the connect timeout fires before connect` + `> propagates a connect-time error event` |
| Daemon returns wider list than caller asked for | (5) Defensive client-side filter post-Zod-parse | `status.test.ts > filters down to the matching meeting when daemon returns wider list` |
| Daemon returns malformed JSON | (6) `dialSocket` throws → server.ts catch maps to envelope | `socket.test.ts > rejects on malformed JSON line from daemon` |
| Daemon returns shape that doesn't match `StatusOutputSchema` | (7) Zod `.parse` throws → server.ts catch | `status.test.ts > throws on a daemon reply that doesn't parse through StatusOutputSchema` |

All 9 vectors land on a typed envelope (no panic, no leak past the MCP boundary).
