# T-4.4 — Manual deeplink verification (host-side)

> Sandbox cannot run `cargo`, `tauri build`, or trigger `LaunchServices`. This
> checklist is for an operator on a Mac with Xcode CLT + Rust toolchain
> installed, executed once after Phase 4 lands.

## Prerequisites

- macOS 12+ (Monterey or later — `LaunchServices` URL scheme registration is stable).
- Xcode Command Line Tools (`xcode-select --install`).
- Rust toolchain (`rustup`, stable channel).
- Tauri 2 CLI (`bun add -d @tauri-apps/cli` already in `package.json`).
- An `ANTHROPIC_API_KEY` in `~/.config/meeting-copilot/.env` (so the app can boot to the start screen).

## Step 1 — Install the deep-link plugin Cargo crate

```bash
cd src-tauri
cargo add tauri-plugin-deep-link@~2
```

Expected: `Cargo.toml` gains `tauri-plugin-deep-link = "2"` under `[dependencies]`. Re-run `cargo build` to confirm the dep tree resolves.

## Step 2 — Register the plugin in `src-tauri/src/lib.rs`

Edit `pub fn run()`. The plugin registration goes **before** `.invoke_handler(...)`:

```rust
.plugin(tauri_plugin_deep_link::init())
.setup(|app| {
    use tauri_plugin_deep_link::DeepLinkExt;
    let handle = app.handle().clone();
    app.deep_link().on_open_url(move |event| {
        for url in event.urls() {
            // Forward to the new `commands::start_from_deeplink` command.
            let _ = handle.emit("meeting-copilot://deeplink", url.as_str());
        }
    });
    // ... existing repo setup stays here ...
    Ok(())
})
```

## Step 3 — Add the `commands::start_from_deeplink` Tauri command

Append to `src-tauri/src/lib.rs` (deferred from Phase 4 sandbox):

```rust
#[tauri::command]
fn start_from_deeplink(state: State<'_, RepoHandle>, url: String) -> Result<(), String> {
    use url::Url;
    let parsed = Url::parse(&url).map_err(|e| format!("invalid deeplink: {e}"))?;
    if parsed.scheme() != "meeting-copilot" {
        return Err(format!("unexpected scheme: {}", parsed.scheme()));
    }
    if parsed.host_str() != Some("start") {
        return Err(format!("unexpected action: {:?}", parsed.host_str()));
    }
    // Pull query params: contextPath (multi), sttProvider, model, privacyMode,
    // ttsProvider, meetingTitle. All percent-decoded by `Url::query_pairs`.
    let mut params: HashMap<String, Vec<String>> = HashMap::new();
    for (k, v) in parsed.query_pairs() {
        params.entry(k.into_owned()).or_default().push(v.into_owned());
    }
    // Dispatch to the same start logic as the UI Start button.
    // (Implementation owned by Phase 4.x — initial host-verify just logs.)
    eprintln!("deeplink params: {:?}", params);
    Ok(())
}
```

Add to `tauri::generate_handler![...]` list:

```rust
.invoke_handler(tauri::generate_handler![
    greet,
    ping,
    read_context_file,
    save_meeting,
    load_meetings,
    start_from_deeplink,  // NEW
])
```

## Step 4 — Build the bundle

```bash
cd src-tauri
cargo build --release
cd ..
bun run tauri build
```

Expected: `src-tauri/target/release/bundle/macos/Meeting Copilot.app` exists. Inspect:

```bash
plutil -p "src-tauri/target/release/bundle/macos/Meeting Copilot.app/Contents/Info.plist" | grep -A 6 CFBundleURLTypes
```

You MUST see:

```
"CFBundleURLTypes" => [
  0 => {
    "CFBundleURLName" => "Meeting Copilot Deep Link"
    "CFBundleURLSchemes" => [
      0 => "meeting-copilot"
    ]
  }
]
```

If `CFBundleURLTypes` is absent, the plugin's bundler hook did not run — re-run with `RUST_LOG=tauri-plugin-deep-link=debug bun run tauri build` and check for hook errors.

## Step 5 — Register with LaunchServices

First-launch trigger (no manual step needed if the app is opened once):

```bash
open "src-tauri/target/release/bundle/macos/Meeting Copilot.app"
```

Verify with:

```bash
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister \
  -dump | grep -A 4 'meeting-copilot'
```

Expected: a matching entry with `claim id: <bundle-id>`.

## Step 6 — Smoke-test the deeplink

```bash
open "meeting-copilot://start?sttProvider=mlx&model=claude-sonnet-4-6&privacyMode=local-first"
```

Expected:
1. Meeting Copilot.app comes to foreground (or launches if not running).
2. Console output (or app log) contains `deeplink params: { … }`.
3. `lsof -p <pid> | grep meeting-copilot.sock` shows the helper-daemon socket once T-4.5 lands.

## Step 7 — End-to-end smoke (after T-4.5 + T-4.6)

```bash
bun run mcp-server &
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"bridge_meeting_start","arguments":{"contextPaths":[],"sttProvider":"mlx","model":"claude-sonnet-4-6","privacyMode":"local-first"}}}' | nc -U /tmp/meeting-copilot-mcp.sock
```

Expected: a JSON-RPC response with `structuredContent.meetingId` (≠ "m-test"; the synthetic from `syntheticHandshake` is test-only).
