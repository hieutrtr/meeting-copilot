## 5. Threat-model walkthrough (R-2 in INDEX)

| Attack vector | Defence layer | Test |
|---|---|---|
| `contextPaths: ["../../etc/passwd"]` | (2) `validateContextPaths` rejects `..` segment | `start.test.ts > rejects ../ traversal in contextPaths with ContextNotFound, BEFORE spawn` |
| `contextPaths: ["..%2Fetc%2Fpasswd"]` | (2) `validateContextPaths` percent-decodes once and rejects | `deeplink.test.ts > rejects percent-encoded traversal` |
| `meetingTitle: "x'; rm -rf /"` | (3) URLSearchParams percent-encodes; (4) spawn array form means no shell parses the value | covered by `start.test.ts > invokes spawn('open', [deeplink], …)` (asserts the shape) + `deeplink.test.ts > URL-encodes shell metachars` |
| `sttProvider: "deepgram"` + `privacyMode: "local-first"` | (3) `isSttProviderAllowed` returns false → `PrivacyModeViolation` envelope | `start.test.ts > rejects local-first + deepgram with PrivacyModeViolation, BEFORE spawn` |
| `sttProvider: "google-cloud-stt"` (out-of-enum) | (1) Zod `.enum()` throws | `start.test.ts > rejects an out-of-enum sttProvider` |
| `secretKey: "yes"` extra field | (1) Zod `.strict()` throws | `start.test.ts > rejects unknown keys with a thrown Zod error` |
| `contextPaths: [<NUL>"]` | (2) `validateContextPaths` rejects NUL | `deeplink.test.ts > rejects a NUL-byte injection` |
| `contextPaths: [<huge string>]` | (1) Zod `.max(4096)` rejects; `validateContextPaths` redundantly rejects too-long | `deeplink.test.ts > rejects a single-path string longer than MAX_CONTEXT_PATH_LEN` |

All 8 vectors land on a typed envelope (no panic, no unintended spawn).
