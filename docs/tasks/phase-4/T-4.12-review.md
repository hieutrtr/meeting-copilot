## 7. Out-of-spec additions / deviations

Two minor deviations from spec §4 / §6 / §10 — flagged here so a future reviewer can see the decision trail:

1. **`src-tauri/tauri.conf.json#version` bumped.** Spec §3.1 enumerated only `package.json` + 4 Cargo `version` fields. The `tauri.conf.json#version` drives `CFBundleShortVersionString` in the notarized DMG; without it bumped, the install handler (T-4.3) would compare `Info.plist v0.0.0` against `expectedVersion 1.0.0` and report a stale install. Caught during pre-flight; bump landed under the same release commit. Spec doc §3.1 supplemented in the §1 row note in this review doc.
2. **DMG-INSTRUCTIONS.md added §0 "Prerequisites".** Spec §5 listed 8 sections (1..8); landed file has 9 (0..8). The extra §0 covers `xcode-select --install` + `xcrun notarytool store-credentials` — one-off operator setup steps that the original §1 "Pre-flight" was overloading. Splitting them into a dedicated §0 makes the "every release" §1 vs "first release ever" §0 boundary clear. Acceptable in spec spirit (operator-side operability) without breaking AC-5.

Nothing in either deviation expands scope or affects security posture; both are clarity-of-operability improvements caught during the review pass.
