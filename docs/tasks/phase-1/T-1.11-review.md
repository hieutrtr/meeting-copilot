## AC checklist

- [x] **AC-1** Public surface — `<AnswerPanel />` is a pure presentational component (props per the task doc); `useAskClaude()` hook returns `{ status, text, error, usage, costUsd, cacheReadRatio, ask, reset }`. AP-S1..S12 cover the panel; AC-H1..H6 cover the hook.
- [x] **AC-2** Incremental render — AP-S2 rerenders the panel with `text="Hello "` then `text="Hello world"`, asserts both intermediate strings reachable AND that the markdown root DOM node identity is stable across rerenders (`expect(root2).toBe(root1)`). No flicker regression possible while the test stays green.
- [x] **AC-3** Markdown render — AP-S3 covers `## H2` heading + `- a / - b` unordered list + `1. one / 2. two` ordered list rendering to `<h2>`, `<ul>/<li>`, `<ol>/<li>`. AP-S4 covers inline `**bold**` and `` `code` `` mapping to `<strong>` + `<code>`. AP-S5 is the XSS gate — `<script>alert(1)</script>` text in input does NOT produce a `<script>` element in the DOM (`react-markdown` v10 default config strips raw HTML).
- [x] **AC-4** Copy button — AP-S6 / AP-S6b: hidden while streaming, visible+enabled when done. AP-S7: click invokes `onCopy(text)` AND flips the button label to "Copied!" (visible via `findByText`). AP-S8: with no `onCopy` prop, click writes to `navigator.clipboard.writeText` instead. The plain-text-vs-markdown distinction in the AC doc reduces to identity in the MVP (the source IS the rendered text); test asserts the literal `text` prop is what was passed to the copy callback.
- [x] **AC-5** Cache-hit badge — AP-S9 with `cacheReadRatio=0.92` shows "Cache hit 92%". AP-S9b with `cacheReadRatio=0.1` and with `cacheReadRatio` absent both show no badge.
- [x] **AC-6** Error fallback — AP-S11 with `status="error", error=new Error(...)` renders a `[role="alert"]` container with the message. AP-S12 paranoid filter strips `sk-ant-…` substrings before render (regression gate). Hook-side AC-H3 + AC-H4 prove `useAskClaude` captures both sync and mid-stream errors into `state.error` instead of throwing into the React render tree.
- [x] **AC-7** Cost readout — AP-S10 with `costUsd=0.0123` renders `$0.0123` (4dp); AP-S10b with no `costUsd` shows no readout. T-1.13 will use this as the visible regression target for the warm-call cost AC ($0.015 advisory).
- [x] **AC-8** Hook error contract — AC-H3 asserts that when `askClaude()` throws `MissingApiKeyError` synchronously (T-1.10 AC-5), `useAskClaude.ask()` does NOT re-throw; instead it surfaces `{ status: "error", error: instanceof MissingApiKeyError }`. The user sees AC-6's friendly fallback, never a React error boundary.

## Self-review

- [x] **Tests pass** — 21 new vitest, 90 total, all green. 0 unhandled rejections (the cancellation path explicitly `await gen.return(undefined)` to drain the stale generator without leaving a dangling promise).
- [x] **AC met** — 8/8 from task doc.
- [x] **No over-engineering.** `react-markdown` is a single dep replacing hand-rolled markdown parsing — bringing this in is cheaper than getting "renders headings + lists + safely escapes raw HTML" right by hand. The hook is ~150 lines including the cancellation guard; the alternative (using `useReducer` + a separate cancellation context) would have added a layer for one consumer. PRD §7.2's Regenerate / Useful / Citations buttons are explicitly out of scope for the MVP demo.
- [x] **Tauri + React + TS strict** — `tsc --noEmit` clean. No `any` outside the necessary `unknown`-cast in `useAskClaude` to widen the discriminated-union event type as it crosses the dynamic `step.value` boundary; the `as` cast there is narrow and immediately back-narrowed by a switch on `event.type`.
- [x] **No secret leak (`ANTHROPIC_API_KEY`).** AP-S12 strips `sk-ant-…` substrings from any rendered error message; T-1.10's CL-S11 already covered the underlying SDK-error path. The hook never logs / serialises the API key (it doesn't see the key — the key flows through `askClaude(input, opts)` directly).
- [x] **Audio buffer cleanup.** N/A — text-only render path.
- [x] **Streaming UI non-blocking.** Each delta calls `setSnapshot((s) => ({ ...s, text: aggregated, status: "streaming" }))` which schedules a React render; deltas land in DOM as soon as React batches them. The driver loop never blocks on anything other than `gen.next()` (the SDK's own promise). The test rerenders intermediate text and asserts it's visible, so flicker is the only failure mode and AP-S2 catches it.
- [x] **No `unwrap()` / no `panic!` reachable.** Pure JS — sync errors caught (`MissingApiKeyError`), async errors caught (`gen.next()` rejects → `try/catch` flips status to `error`), copy errors swallowed (UI just doesn't flip to "Copied!").
- [x] **Cancellation correctness.** AC-H6 asserts a second `ask()` cancels the first by incrementing `requestIdRef.current` and gating every `setState` on `requestIdRef.current === myId`. The stale generator gets `gen.return(undefined)` to politely abort. Releasing the gated first-runner late (`releaser.fn?.()` after the second ask completes) does NOT pollute state — the test sleeps 5 ms after release and reasserts the final text.

## Risks revisited

- **`react-markdown` bundle weight (~30 KB gz)** — accepted; lib has no functional alternative for "render partial markdown safely". Bundle-budget check lands in Phase 1.x packaging (raw plan T-1.13 deferred).
- **`react-markdown` v10 streams partial input safely** — confirmed by AP-S2's mid-stream rerender (text="Hello " mid-stream renders without throwing on the trailing space) and the broader streaming flow tested in AC-H2.
- **Re-ask race** — covered by AC-H6 with a deliberately gated first runner. The request-id gate is the only correctness guarantee; AC-H6 is the regression test.
- **`navigator.clipboard` mock churn under jsdom** — AP-S8 installs the mock AFTER `userEvent.setup()` because user-event v14 stubs `navigator.clipboard` for its own copy/paste keyboard handling. Documented in the test comment so a future edit doesn't reintroduce the order bug.
- **Live cache-hit badge percent depends on T-1.10's `cacheReadRatio`** — already proven structurally in T-1.10 CL-S9; T-1.13 will re-verify against a real warm call.
- **Hot-reload mid-stream `setState` on unmounted** — covered: `useEffect` cleanup increments `requestIdRef.current`, every `setState` is gated on `mountedRef.current && requestIdRef.current === myId`.
