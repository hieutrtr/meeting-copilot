## AC checklist

- [x] **AC-1** Public surface — `askClaude(input, opts?)` returns `AsyncGenerator<AskClaudeEvent, AskClaudeResult>`. CL-S8 + CL-S9 prove the for-await delta path AND the `step.value` final-result path.
- [x] **AC-2** Request shape — CL-S2 + CL-S3 + CL-S4 + CL-S5 cover model/max_tokens/temperature, both system blocks `cache_control: ephemeral`, and the user message's 2 non-cached parts.
- [x] **AC-3** Byte-identical body — CL-S7 makes 2 calls with the same input and asserts `JSON.stringify(body1) === JSON.stringify(body2)`. The prompt-cache key hashes on the exact bytes of `system[*]`, so this is the regression gate.
- [x] **AC-4** Streaming — CL-S8 collects deltas as they arrive (`["hel", "lo", " world"]`) and asserts the order. Internal `DeltaQueue` (microtask-based, push/pull) means a `for await` consumer sees each fragment as soon as the SDK fires `text`, not after the full response.
- [x] **AC-5** Missing API key — CL-S1 asserts `expect(() => askClaude(...)).toThrow(MissingApiKeyError)` (synchronous, before generator entry). Env var = empty string also counts as missing (covered by CL-S1b's empty-string assignment).
- [x] **AC-6** No secret leak — CL-S1b's regex check (`expect(msg).not.toContain("sk-ant-")`) + CL-S11's check (`expect(error.message).not.toContain("test-key")`) cover both the missing-key path and the SDK-error-propagation path.
- [x] **AC-7** Usage + cost — CL-S9 asserts `result.usage.cache_read_input_tokens === 22_000`, `result.cacheReadRatio > 0.99`, `result.costUsd > 0`, `result.stopReason === "end_turn"`. `pricing.test.ts` covers the math against the published Sonnet 4.6 schedule.
- [x] **AC-8** Empty-transcript fallback — CL-S6 sends `recentTranscript: ""` and asserts `body.messages[0].content[0].text` contains `"(no recent transcript yet)"`. Without this, AC-3 would only hold when the user has marked a question with at least one transcript chunk in flight.

- [x] **No secret leak (`ANTHROPIC_API_KEY`).** The key is read once in `resolveApiKey()`, passed into the SDK ctor, and never logged, returned, or surfaced in errors. CL-S1b + CL-S11 are the regression gates.
- [x] **Audio buffer cleanup.** N/A — text-only path. Audio cleanup (Drop on `CpalMicSource`, ring-buffer drop-no-panic) lives in T-1.3 / T-1.4.

- [x] **No `unwrap()` / no `panic!` reachable.** Pure JS — `MissingApiKeyError` is the only synchronous throw; SDK errors propagate via `queue.fail(...)` → `queue.next()` rejects → generator throws into the consumer's `for await`. No silent swallow.

## Risks revisited

- **SDK type drift on `.on("text", …)`** — the cast inside `runStream` keeps the implementation honest about which type contract we're depending on. If 0.50+ ships a typed `StreamEvents` definition we drop the cast in a single line. Pin `^0.40.0` matches T-0.5 spike.
- **`finalMessage()` rejection unhandled** — caught by the iteration on this loop step; surfaced through the queue so the rejection has exactly one consumer (the generator). CL-S11 covers it.
- **Cache key drift from accidental object-spread of user input** — `buildRequest` only constructs the typed fields; no `...input` spread anywhere. CL-S7 is the regression gate.
- **Live cost AC ($0.015 advisory)** — CL-S13 covers the math; live verification lands in T-1.13 once `ANTHROPIC_API_KEY` is in env.
- **Hot-reload cancels mid-stream** — generator naturally exits when the consumer stops `for await`-ing; T-1.13's React effect cleanup will call `.return()` to ask the SDK to abort. For now the demo path doesn't hot-reload mid-stream so this is deferred.
