## Acceptance Criteria (verbatim from INDEX)

> **T-1.11** — `AnswerPanel` UI: streaming markdown render + copy-button. **AC:** mock token-stream fed → answer area updates incrementally without flicker; markdown headings + lists render correctly; Copy button copies plain text. Dep: T-1.10.

Decomposed:

- **AC-1** Public surface: a presentational `<AnswerPanel />` and a driver hook `useAskClaude()`.
  - Hook signature: `useAskClaude(): { status, text, error, usage?, costUsd?, cacheReadRatio?, ask(input), reset() }`. The hook owns the in-flight async-generator and the `useState`-driven aggregation; the panel is pure render.
  - Component props: `{ status: "idle" | "streaming" | "done" | "error"; text: string; error?: Error | null; usage?: AnthropicUsage; costUsd?: number; cacheReadRatio?: number; onCopy?: (text: string) => void | Promise<void> }`. No store/global access — keeps tests free of zustand resets.
- **AC-2** **Incremental render** — when the SDK fires N deltas (`["This is ", "the ", "answer."]`), each delta lands in the DOM in order. Test asserts intermediate text content is reachable via `await screen.findByText(...)` between deltas, not just the aggregated final string. No `key`-churn re-mount: the markdown root keeps its identity across deltas (regression gate for React 18's batching reset).
- **AC-3** **Markdown render** — headings (`# H1`, `## H2`), unordered lists (`- item`), ordered lists (`1. item`), inline code (`` `x` ``), and bold/italic emphasis render to the corresponding HTML elements. Implementation uses `react-markdown` (sanitizes by default; renders partial/in-flight markdown without throwing — important during streaming when a `## ` heading line may not yet have the trailing newline). No raw HTML allowed in the rendered tree (XSS gate — test feeds `<script>alert(1)</script>` and asserts the script text is escaped, not executed).
- **AC-4** **Copy button** — clicking the Copy button calls `navigator.clipboard.writeText(text)` (or `props.onCopy(text)` if provided) with the **plain text** of the answer (not the markdown source — but for the MVP the source is the plain text, so the assertion is `text === aggregated`). Visible only when `status === "done"` (no half-streamed copies). Disabled while streaming. After a successful copy, the button briefly shows a "Copied!" affordance (testable via `findByText(/copied/i)`).
- **AC-5** **Cache-hit indicator** — when `cacheReadRatio > 0.5`, the panel shows a small "Cache hit" badge (with the percentage). When the ratio is undefined/zero, no badge. Surfaces the AC-7 result of T-1.10 to the user without forcing them to open devtools.
- **AC-6** **Error fallback** — when `status === "error"`, the panel renders `error.message` inside a `[role="alert"]` container with a class hook for styling. **Never** echoes the API key. (T-1.10's `MissingApiKeyError` already excludes the key from `.message`; this AC is the consumer-side gate.)
- **AC-7** **Cost readout** — when `costUsd !== undefined`, the panel shows `$0.XXX` formatted to 4 decimals. Cosmetic but a directly-visible regression target for T-1.13 live smoke (warm call should land < $0.015 per spike-memo C-3).
- **AC-8** **Hook error contract** — `MissingApiKeyError` thrown synchronously by `askClaude` (T-1.10 AC-5) is caught by `useAskClaude.ask(input)` and surfaced as `{ status: "error", error }` instead of a render-tree exception. The user sees AC-6's friendly fallback, not a React error boundary.

Out of scope: regenerate, useful/unhelpful feedback buttons (PRD §7.2 wireframe shows them but loop INDEX defers to Phase 1.x), citations rendering (deferred — Phase 2 once retrieval is wired), persistence into `Answer` row (T-1.12), live cost/latency bench (T-1.13).

### Component tests — `src/components/AnswerPanel.test.tsx`

| ID | Case | Asserts |
|---|---|---|
| **AP-S1** | Idle render | `status="idle"` → no answer body, no Copy button. Just placeholder ("Mark a question to see the answer here"). |

| **AP-S3** | Markdown headings + lists render to HTML elements | `text="## Sub\n\n- a\n- b\n\n1. one\n2. two"` → `getByRole("heading", { level: 2 })`, `getAllByRole("listitem")` length 4, two `<ul>`/`<ol>` containers. |

| **AP-S5** | Raw HTML escaped (XSS gate) | `text="<script>alert(1)</script>"` → no `<script>` element in the tree; the literal text appears as `&lt;script&gt;...` (or as inert text content). |
| **AP-S6** | Copy button visible only when done | `status="streaming"` → no Copy button (or disabled). `status="done"` → button rendered + enabled. |
| **AP-S7** | Copy click invokes onCopy with plain text | Click "Copy" → `onCopy` called with the `text` prop. After resolve, "Copied!" affordance shown. |
| **AP-S8** | Copy fallback to navigator.clipboard | When `onCopy` not provided, click writes to `navigator.clipboard.writeText`. Test mocks clipboard before render. |
| **AP-S9** | Cache-hit badge shows when ratio > 0.5 | `cacheReadRatio=0.92` → badge "Cache hit 92%" reachable via `getByText`. `cacheReadRatio=0.1` → no badge. |
| **AP-S10** | Cost readout 4dp | `costUsd=0.0123` → `getByText("$0.0123")`. `costUsd=undefined` → no `$` text. |
| **AP-S11** | Error fallback in [role=alert] | `status="error", error=new Error("upstream 503")` → `getByRole("alert")` text contains "upstream 503". No render-tree throw. |
| **AP-S12** | Error never echoes API key shape | `error=new Error("api error: sk-ant-test...")` → fail (regression gate). ### Hook tests — `src/hooks/useAskClaude.test.ts`

| ID | Case | Asserts |
|---|---|---|
| **AC-H1** | Initial state idle | `result.current.status === "idle"`, `text === ""`, `error === null`. |
| **AC-H2** | Ask drives streaming | Mock `askClaude` to yield `["he", "llo"]` deltas + final usage. `act(() => result.current.ask(input))`. After one delta, `status === "streaming"` and `text === "he"`. After all, `status === "done"`, `text === "hello"`, `usage` populated, `costUsd > 0`. |
| **AC-H3** | Synchronous MissingApiKeyError captured | `askClaude` throws `MissingApiKeyError` synchronously. `result.current.ask(input)` does NOT re-throw; instead `status === "error"`, `error instanceof MissingApiKeyError`. |
| **AC-H4** | SDK error mid-stream captured | Generator throws on `.next()`. After `ask`, `status === "error"`, `error.message` matches thrown message. Partial `text` (deltas seen before throw) preserved. |
| **AC-H5** | Reset clears state | After done, `reset()` → `status === "idle"`, `text === ""`, `usage === undefined`. |
| **AC-H6** | Re-ask cancels prior stream | `ask(input1)` then `ask(input2)` mid-stream. Final state reflects only `input2`'s deltas, not concatenated. Test uses a controllable generator gate. |

### Integration — wiring in `App.tsx`

The App wires `<AnswerPanel />` after `<TranscriptView />`, and `useQuestionStore.questions[0]` triggers `useAskClaude.ask(input)` via a `useEffect`. The `useEffect` is gated on `useContextStore.content` being non-null (the cache-key-stable path). No new tests in `App.test` since none exists yet — the integration smoke happens in T-1.13.

## Risk + mitigation

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| `react-markdown` adds runtime weight (~30 KB gz) | High | Low | Single consumer, replaces hand-rolled parser bugs; canonical lib for MVP; revisit in Phase 1.x packaging if bundle budget tightens. |
| Streaming partial markdown crashes `react-markdown` (e.g. unclosed code-fence) | Medium | High | `react-markdown` already tolerates partial input. AP-S2 test feeds mid-token text to confirm. |
| `navigator.clipboard.writeText` unavailable under jsdom | High | Low | Test mocks `navigator.clipboard` before render; component falls back to `onCopy` prop in production if needed. |
| Hook re-renders trigger re-runs of `useEffect` and double-fire `ask` | Medium | High | `useAskClaude` keeps an internal `current` ref to the running generator; `ask` checks `current === null` before kicking off; explicit `reset()` clears. AC-H6 covers re-ask. |
| Sync `MissingApiKeyError` slips past the React render path | Medium | High | `useAskClaude.ask` wraps the call in try/catch BEFORE entering the for-await; AC-H3 is the regression gate. |
| API key leaks into rendered error message | Low | High (sec) | T-1.10 AC-5/AC-6 are the primary gate; AC-6 + AP-S12 paranoid filter strips `sk-ant-` substrings. |
| `react-markdown` injects raw HTML when fed `<script>` | Low | High (sec) | Default `react-markdown` strips raw HTML; AP-S5 test asserts. |
| Re-mount of markdown root causes flicker (AC-2 regression) | Low | Medium | Single root element keyed by `status !== "idle"` only, not by `text`. AP-S2 asserts ref identity across rerenders. |
