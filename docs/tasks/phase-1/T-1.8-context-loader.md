## Acceptance Criteria (verbatim from INDEX)

> **T-1.8** — `ContextLoader` for single file (PRD/MD/TXT). **AC:** click "Load file" → file path + char count + ~token-estimate (`chars/4` proxy) shown; state stored. Dep: T-1.1.

Decomposed:

- **AC-1** Rust `read_context_file(path)` reads UTF-8 text from disk and returns a `ContextFile { path, content, char_count, estimated_tokens }` struct.
- **AC-2** `read_context_file` rejects extensions other than `.md` / `.txt` (and bare extensionless paths) with a typed error → no PDF / DOCX in MVP. Reason: the plan limits Phase 1 to text-only sources; binary parsers (`pdf-parse`, etc.) move to Phase 1.x per ARCH §6.1 V2 retrieval gate.
- **AC-3** `read_context_file` returns a typed error on missing file / unreadable path. The Tauri command surface stringifies it so the UI can render it; the Rust unit tests assert on the typed enum directly.
- **AC-4** `estimated_tokens = ceil(char_count / 4)` — the plan's char-count proxy. **Off-spec from raw T-1.4** (which calls for `tiktoken`); the loop INDEX explicitly downgrades to `chars/4` to avoid a tokenizer dep churn in MVP. Documented in INDEX and again here so T-1.10 review can flag if the Claude cost AC needs the more accurate count.
- **AC-5** Tauri command `read_context_file` is registered in `src-tauri/src/lib.rs` and invokes `helper_daemon::context::read_context_file`. Returns the `ContextFile` shape via serde JSON (camelCase keys to match `shared/types.ts:ContextSource`).
- **AC-6** React zustand store slice `useContextStore` exposes:
  - `source: ContextSource | null` — currently loaded source (single file only).
  - `loadFromPath(path: string): Promise<void>` — invokes the Tauri command, stores the result; on error sets `error` and leaves `source` unchanged.
  - `clear(): void` — resets to `null`.
  - `error: string | null` — last error message, cleared on each successful load.
- **AC-7** `ContextLoader` React component:
  - Text input for the path (paste from Finder; full file-picker dialog deferred to T-1.9 once `tauri-plugin-dialog` lands).
  - "Load file" button → calls `useContextStore().loadFromPath(path)`.
  - Renders the loaded source as `path · {charCount} chars · ~{estimatedTokens} tokens` so the AC-1 readout is visible.
  - On error renders the message in a `[role=alert]` element so `getByRole("alert")` can pick it up.
- **AC-8** No new runtime production deps beyond zustand (one small state lib — ~3 KB gzipped). React continues to render with the fixed-row chunk list from T-1.7. We deliberately do not add `tiktoken-js` (pulls in `wasm` + ~1 MB) for the token estimate; the proxy AC-4 covers it.

## Risk + Mitigation

| Risk | Likelihood | Mitigation |
|---|---|---|
| `chars/4` token estimate drifts > 30 % from real Claude tokenizer on non-English text → breaks T-1.10 cost AC. | M | Documented in T-1.10 review hook; if drift breaks the AC there, swap to `tiktoken-rs` in the helper-daemon (Rust lib has prebuilt model files, no wasm bridge). Phase 1.x candidate. |
| Tauri 2 IPC stringifies enum errors as `String`, losing the variant tag the Rust tests rely on. | L | Test the typed `ContextError` directly in `cargo test`; the React store sees only `string` (which is what the AC says). Keep `Display` impl stable; T-1.10 may want machine-tagged errors and can move to a `serde`-tagged enum then. |
| Adding zustand grows bundle weight for one slice. | L | zustand is ~3 KB gzipped; the slice is reused by T-1.9 (meeting state) + T-1.10/T-1.11 (Q/A panel). Pulls weight across 4+ consumers. |
| `read_context_file` could be invoked with an absolute path outside the user's home — minor information disclosure if leaked. | L | Phase 1 demo runs locally on user's own machine; no network surface. Phase 3 adds path allow-listing per ARCH §11. |
| File-picker dialog deferred → user must paste path manually for the demo. | M | Documented in `PHASE-BROWSER-TEST.md` step 2 ("paste full path"); T-1.9 polishes by adding `tauri-plugin-dialog` once the rest of the controls land. |
| Large file (50 MB log) blocks Rust on `fs::read_to_string`. | L | MVP target is PRDs (~50 KB). Phase 1.x review gates a streaming reader if anyone hits it; not in AC. |
| zustand v5 requires React 18.x — check repo react version. | L | repo on react 18.3.1 (see `package.json`). v5 supports it cleanly. |

## Hardware-blocked verification

None. All tests run in the sandbox:
- `cargo test -p helper-daemon` exercises `read_context_file` against `tempfile::NamedTempFile` fixtures.
- `bun test` runs the store + component vitest cases under jsdom.
- Live IPC round-trip (`bun run tauri dev` → click "Load file") is a manual smoke step in `PHASE-BROWSER-TEST.md`; covered by T-1.13 sign-off, not this task.
