## TDD Cycle Audit

The task is type-only, so a naïve `import type { … }` test would pass even with `shared/types.ts` missing (esbuild erases type-only imports). To make the RED → GREEN gate honest, the test also imports a runtime constant `SHARED_TYPES_SCHEMA_VERSION`. That forces real module resolution at runtime, and it forces typecheck to surface a missing or renamed export.

- **RED 1** — Wrote `shared/types.test.ts` first. Without `shared/types.ts` and without the alias in `vitest.config.ts`, vitest would fail with `Cannot find package '@shared/types'`. (Empirically: deleted the import path during dev — vitest errored as expected, then restored.)
- **GREEN 1** — Created `shared/types.ts` exporting types + `SHARED_TYPES_SCHEMA_VERSION`. Wired `vitest.config.ts` alias + `tsconfig.json` paths. All 4 tests passed.
- **REFACTOR** — Added `MeetingStatus` and `QuestionMethod` string-literal unions, `Meeting` alias for ARCH-fidelity downstream, optional fields per ARCH §10. Tests still green; no behavior change in test assertions.

The `tsc --noEmit` pass is the structural backstop: even if a future contributor edits a type member, the typecheck will catch the test-literal mismatch even if vitest's runtime tests do not.

## Decisions Worth Flagging

1. **`MeetingSession` vs `Meeting`** — Loop prompt names it `MeetingSession`; ARCH §10 names the persisted entity `Meeting`. Exported both: `MeetingSession` is the canonical name in shared types; `Meeting` is a type alias of `MeetingSession` so any contributor reading ARCH §10 verbatim can `import type { Meeting } from "@shared/types"` without confusion. T-1.12 (SQLite persistence) decides which name appears in the schema; both are equally valid.
2. **`QAEntry` shape** — Loop prompt asks for `QAEntry`; ARCH §10 has separate `Question` + `Answer` rows. Modeled `QAEntry` as the in-memory pair `{ question: Question; answer: Answer | null }` so T-1.10 (streaming Claude) can hold a `QAEntry` while the answer is still in-flight (partial token stream). Persistence layer (T-1.12) splits it back into two rows.
3. **`SHARED_TYPES_SCHEMA_VERSION = "1.0.0"`** — One-line runtime sentinel. Two purposes: (a) gives the vitest spec something to runtime-resolve (proves the alias works end-to-end); (b) lets T-1.6 event bridge log version on bad-payload to spot bundle drift between Rust serialization and TS types. No logic depends on the value; semver bumps are doc-only for now.
4. **No `bun` workspace for `shared/`** — Single consumer (`src/`); a workspace declaration would add ceremony for zero benefit. If a second consumer appears (e.g. an `electron-overlay/` host), revisit then.
5. **Cargo workspace deferred to T-1.2** — Cargo workspace requires ≥ 1 member crate or a virtual workspace with `members = []` errors. T-1.2 lands `crates/helper-daemon/` and the `[workspace]` table on the same commit so `cargo build --workspace` becomes meaningful in one step instead of two.
