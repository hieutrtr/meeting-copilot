## Risks revisited (from task doc)

- **SDK shape drift** — the FakeAnthropic in E2E.test.tsx mirrors `claudeClient.test.ts` exactly. Future SDK upgrade fails T-1.10 first; T-1.13 inherits the regression gate.
- **Save fires twice on parent re-render** — confirmed regression-gated by E13. The `lastSavedIdRef` guard + the `[status]`-only dep array are the two checks that prevent it.
- **`loadMeetings` rejects on fresh install** — the hook treats it as soft-fail (`console.warn`, `pastMeetings = []`). E11b is the regression gate.
- **Save fires while answer mid-stream** — by design ("your data is saved at the moment you press Stop"). The E2E test happens to wait for the stream to finish before clicking Stop, so the saved `answer.text` is the final text. Phase 1.x can add a "wait for answer before allowing stop" UX gate.
- **Tauri State + setup-time DB open** — `Repo::open` is synchronous + cheap; the setup hook's error path returns the formatted error to Tauri's startup which surfaces it to the user. If the path doesn't exist, `create_dir_all` creates it (with default permissions matching the user's umask).
- **Test pollution from zustand singletons** — every test resets all stores in `beforeEach` + `afterEach`. The hook test additionally calls `cleanup()` to unmount React components.
- **MeetingSnapshot Rust↔TS drift** — E7's mock recorder captures the snapshot; the assertion structure mirrors `helper_daemon::MeetingSnapshot`'s field names. A future drift on either side breaks the assertion immediately.
